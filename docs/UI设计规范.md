# 好奇图鉴 UI 设计规范

> 版本：v1.0
> 适用范围：微信小程序 MVP（iOS / Android）
> 设计基调：自然、轻盈、有温度，避免过度科技感与低龄化

---

## 1. 整体风格

### 1.1 视觉方向

- **风格关键词**：自然、清新、克制、有探索感
- **表现方式**：大圆角、柔和阴影、充足留白、低饱和自然色系
- **气质定位**：不是冷冰冰的识别工具，也不是卡通化的儿童应用，而是给城市成年人用的"轻自然笔记"

### 1.2 色彩系统

#### 主色调

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 主色 | `#3D8B5E` | 主按钮、核心图标、导航选中态、价格/数字强调 |
| 主色浅 | `#E8F5E9` | 按钮hover/按下态背景、标签浅底、进度条背景 |
| 主色深 | `#2C6E4B` | 标题、重要文字、图标填充 |

#### 背景与表面色

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 页面背景 | `#FAFBF7` | 所有页面底层背景，略带暖调，减少纯白刺眼感 |
| 卡片背景 | `#FFFFFF` | 内容卡片、弹窗、列表项 |
| 分隔线 | `#EDF0E9` | 列表分隔、卡片边框 |

#### 文字色

| 用途 | 色值 | 使用场景 |
|------|------|----------|
| 主文字 | `#1F2937` | 页面标题、物种名称、重要正文 |
| 次级文字 | `#6B7280` | 说明文字、时间地点、分类信息 |
| 辅助文字 | `#9CA3AF` | 占位符、禁用态、最弱层级文字 |
| 反白文字 | `#FFFFFF` | 按钮上、深色背景上 |

#### 功能色 / 稀有度标签色

| 用途 | 色值 | 文字色 | 使用场景 |
|------|------|--------|----------|
| 首次发现 | `#10B981` | `#047857` | 绿色胶囊，代表"新物种" |
| 连续 N 天 | `#F59E0B` | `#B45309` | 橙色胶囊，streak 激励 |
| 夜间发现 | `#8B5CF6` | `#6D28D9` | 紫色胶囊，时间特殊标签 |
| 提示/警告 | `#E9C46A` | `#92400E` | 黄色提示条，识别不确定 |
| 错误/失败 | `#EF4444` | `#991B1B` | 失败状态、删除确认 |
| 信息/手动 | `#6B7280` | `#374151` | 灰色提示条，手动搜索模式 |

## 2. 字体规范

### 2.1 字体栈

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

微信小程序优先使用系统字体，不引入外部字体包，保证加载速度与可读性。

### 2.2 字号层级

| 层级 | 字号 | 行高 | 字重 | 使用场景 |
|------|------|------|------|----------|
| 页面大标题 | `48rpx` | `64rpx` | `bold` | 首页品牌名"好奇图鉴" |
| 页面标题 | `40rpx` | `56rpx` | `bold` | 各页面顶部标题 |
| 模块标题 | `32rpx` | `48rpx` | `600` | "最近发现"、"收集进度"等区块标题 |
| 卡片标题 | `30rpx` | `44rpx` | `600` | 物种名称、徽章名称 |
| 正文 | `28rpx` | `44rpx` | `400` | 描述文字、菜单项 |
| 辅助说明 | `24rpx` | `36rpx` | `400` | 时间地点、分类标签、来源署名 |
| 极小字 | `22rpx` | `32rpx` | `400` | 角标、提示、版权信息 |

### 2.3 字重规则

- 标题：统一使用 `bold` 或 `600`
- 正文：统一使用 `400`
- 数字统计（如发现数、连续天数）：使用 `bold`，可适当放大 10%
- 页面中同一层级文字字重不超过 2 种

## 3. 间距与布局

### 3.1 间距系统

以 `8rpx` 为基准单位：

| 名称 | 数值 | 使用场景 |
|------|------|----------|
| xs | `8rpx` | 图标与文字间距、标签内边距 |
| sm | `16rpx` | 卡片内部元素间距 |
| md | `24rpx` | 卡片内边距、表单字段间距 |
| lg | `32rpx` | 页面水平内边距、模块之间间距 |
| xl | `48rpx` | 大模块间距、页面顶部安全距离 |

### 3.2 页面边距

- 所有页面内容区左右内边距统一为 `32rpx`
- 顶部安全区：`48rpx`（适配刘海屏）
- 底部安全区：`48rpx`（适配 home indicator / tabBar）

### 3.3 容器规范

- 卡片默认宽度：`100% - 64rpx`（即左右各 32rpx 边距）
- 最大内容宽度：无上限，小程序全宽
- 双列网格间距：`16rpx`
- 四列/六列网格间距：`12rpx`

## 4. 通用组件样式

### 4.1 按钮

#### 主按钮（拍一张 / 收入图鉴 / 保存图片）

- 高度：`96rpx`

- 圆角：`48rpx`（全圆角胶囊）
- 背景：`#3D8B5E`
- 文字：`#FFFFFF`，`32rpx`，`600`

- 按下态：背景变为 `#2C6E4B`，阴影减弱
- 禁用态：背景 `#A7F3D0`，文字 `#FFFFFF`

#### 次按钮（手动搜索 / 重新拍摄）

- 高度：`80rpx`
- 圆角：`40rpx`
- 背景：`#FFFFFF`
- 边框：`2rpx solid #3D8B5E`
- 文字：`#3D8B5E`，`28rpx`，`500`
- 按下态：背景 `#E8F5E9`

#### 文字按钮（编辑 / 删除 / 查看完整）

- 高度：自适应
- 文字：`#3D8B5E`，`28rpx`，`500`
- 按下态：透明度 0.7

#### 内容卡片

- 背景：`#FFFFFF`

- 高度：`88rpx`

- 聚焦态：边框变为 `#3D8B5E`

### 4.4 标签 / 胶囊

#### 稀有度标签

- 高度：`40rpx`
- 左右内边距：`16rpx`
- 圆角：`20rpx`

#### 分类筛选标签

- 高度：`56rpx`

- 圆角：`28rpx`

## 6. 图标风格建议

### 6.1 风格

- **线性图标为主**，2rpx 描边，圆角端点（stroke-linecap: round）
- 避免纯面性图标，保持界面轻盈；仅在 tabBar 选中态使用主色填充
- 自然主题：叶子、昆虫、鸟类、蘑菇、定位、相机等元素可适当加入有机曲线

### 6.2 尺寸规范

| 场景 | 尺寸 |
|------|------|
| 列表左侧图标 | `48rpx` |
| 按钮内图标 | `36rpx` |
| TabBar 图标 | `48rpx` |
| 导航栏图标 | `40rpx` |
| 徽章图标 | `56rpx` |
| 稀有度标签前小圆点 | `16rpx` |

### 6.3 图标使用原则

- 同一页面内图标风格统一（线性/描边粗细一致）
- 重要操作图标（拍照、保存）使用主色填充
- 辅助图标（展开、箭头、编辑）使用 `#6B7280`
- 徽章未解锁态：整体灰度 + 透明度 0.5

## 7. 动画与交互

### 7.1 过渡动画

- 页面切换：使用微信小程序默认滑动动画，不自定义
- 弹窗出现：`transform: translateY(100%) → translateY(0)`，duration 300ms，easing ease-out
- 遮罩淡入：`opacity 0 → 1`，duration 200ms

### 7.2 按钮反馈

- 按下态：背景加深或透明度 0.9
- 缩放反馈：按下 scale(0.98)，duration 100ms
- 禁用态：透明度 0.5，无按下反馈

### 7.3 加载态

- 识别中：扫描线动画，颜色 `#3D8B5E`，高度 4rpx
- 列表加载：骨架屏或局部 loading，圆形 spinner，主色
- 按钮 loading：右侧 28rpx spinner，文字变为"保存中..."

## 8. 可访问性

- 主文字与背景对比度 >= 4.5:1
- 按钮高度 >= 80rpx，便于点击
- 图片默认加占位背景与 alt/aria 描述
- 关键状态（成功/失败/警告）不仅依赖颜色，同时有图标和文字说明
