# 《好奇图鉴》手绘风格设计规范

> **版本**：v1.0  
> **日期**：2026-08-05  
> **风格名**：手账素描风（Sketchbook）  
> **适用平台**：微信小程序

---

## 一、设计哲学

### 1.1 核心调性
- **像一本随身携带的自然观察手账**，而不是一个冰冷的工具 App
- 每一笔都带有人工痕迹：边框不规整、圆角不对称、元素微微旋转
- 色彩克制：以铅笔灰 + 纸张米黄为底，用蜡笔色块点缀功能标签

### 1.2 与精致版的差异

| 维度 | 精致极简版 | 手绘手账版（本规范） |
|------|-----------|-------------------|
| 边框 | 1px 细线，规整圆角 | 2-3px 粗线，不规则 wobbly 圆角 |
| 颜色 | 纯白背景，灰阶文字 | 米黄纸张色，铅笔灰文字 |
| 字体 | 系统无衬线（干净） | 等宽/手写体（温暖、随性） |
| 阴影 | 柔和弥散阴影 | 无阴影，用「双层边框」模拟手绘厚度 |
| 交互反馈 | 变暗、缩放 | 轻微旋转（±1~3°）、位移 |
| 质感 | 数字产品 | 素描纸 + 铅笔 + 蜡笔 |

## 二、色彩系统

### 2.1 主色板

| 色名 | 色值 | 用途 |
|------|------|------|
| **纸张白** | `#faf8f3` | 页面背景、卡片底色 |
| **铅笔灰** | `#3a3a3a` | 主文字、主边框、图标 |
| **浅灰** | `#888888` | 次要文字、辅助信息 |
| **淡灰** | `#999999` | hint 文字、禁用态 |
| **米白** | `#f5f5f0` | 缩略图背景、空态背景 |

### 2.2 功能色（蜡笔色块）

所有功能色都带**12% 透明度的浅色背景 + 纯色边框/文字**，模拟蜡笔涂色效果。

| 色名 | 色值 | 背景色 | 用途 |
|------|------|--------|------|
| **新绿** | `#4a9b5c` | `rgba(74, 155, 92, 0.12)` | 首次发现标签、成功态 |
| **暖橙** | `#c9a227` | `rgba(201, 162, 39, 0.12)` | 连续 streak 标签、警告态 |
| **夜紫** | `#7c5bbf` | `rgba(124, 91, 191, 0.12)` | 夜间发现标签（v1.0） |
| **冰蓝** | `#4a7c9b` | `rgba(74, 124, 155, 0.12)` | 反季节标签（v1.2） |
| **砖红** | `#b85450` | `rgba(184, 84, 80, 0.12)` | IUCN 濒危标签（v1.2） |

### 2.3 渐变（仅用于照片占位区）

/* 身份证照占位 */

/* 分享卡片顶部 */
background: linear-gradient(135deg, #e8f5e9 0%, #d4edda 100%);

## 三、字体规范

### 3.1 字体栈

```css
font-family: 'Courier New', 'Menlo', 'Monaco', monospace;
```

> **说明**：微信小程序不支持外部字体文件（如 Google Fonts 的 Zeyada），因此使用系统自带的等宽字体模拟「打字机/手写」质感。等宽字体的天然机械感反而强化了「人工记录」的氛围。

### 3.2 字号层级

| 层级 | 字号 | 字重 | 用途 | 特殊处理 |
|------|------|------|------|---------|
| **H1** | 26px | 700 | 页面大标题（如「好奇图鉴」） | `transform: rotate(-1deg)` |
| **H2** | 22px | 700 | 模块标题（如「我的图鉴」） | `transform: rotate(-0.5deg)` |
| **H3** | 18px | 700 | 子标题（如「识别结果」导航栏） | 无 |
| **H4** | 14px | 700 | 卡片标题、区块标签 | 无 |
| **Body** | 13px | 400 | 正文、描述 | 无 |
| **Caption** | 12px | 400 | 时间、地点、元信息 | 无 |
| **Hint** | 12px | 400 | 辅助提示、空态 | 颜色 `#999` |
| **Badge** | 10-11px | 700 | 标签文字 | 无 |

## 四、间距与布局

### 4.1 页面安全区

```
┌─────────────────────────────┐
│  状态栏 44px                 │
├─────────────────────────────┤
│                              │
│  内容区                      │
│  左右边距：20px              │
│                              │
├─────────────────────────────┤
│  底部导航 64px               │
└─────────────────────────────┘
```

### 4.2 间距 token

| Token | 值 | 用途 |
|-------|---|------|
| `xs` | 4px | 图标与文字间隙、标签内边距 |
| `sm` | 8px | 元素间小间隙、卡片内边距 |
| `md` | 12px | 列表项间距、按钮内边距 |
| `lg` | 16px | 区块间距、页面边距 |
| `xl` | 20px | 大模块间距、卡片外边距 |
| `xxl` | 24px | 页面顶部留白 |

### 4.3 布局原则
- 所有卡片、按钮、输入框**左右边距统一 20px**
- 列表项之间间距 **10-12px**
- 不使用网格系统，允许轻微「错位」以强化手绘感

## 五、边框与圆角（核心视觉特征）

### 5.1 手绘边框规范

**所有可见边框必须满足以下特征**：

1. **线宽**：2px 或 2.5px（比常规 1px 粗，模拟铅笔/马克笔）
2. **颜色**：`#3a3a3a`（铅笔灰）
3. **圆角不对称**：不使用标准 `border-radius`，而是四个角分别定义

```css
/* 标准卡片 */
border: 2.5px solid #3a3a3a;
border-radius: 4px 16px 8px 12px;

/* 小按钮 */
border: 2px solid #3a3a3a;
border-radius: 6px 3px 8px 5px;

/* 大按钮/拍照区 */
border: 3px solid #3a3a3a;
border-radius: 4px 24px 8px 20px;

/* 圆形元素（头像、相机按钮） */
border: 3px solid #3a3a3a;
border-radius: 50%; /* 圆形保持对称 */
```

### 5.2 双层边框（模拟手绘厚度）

关键元素（拍照区、仪表盘、分享卡片）使用**伪元素双层边框**：

```css
.element {
  position: relative;
  border: 3px solid #3a3a3a;
  border-radius: 4px 24px 8px 20px;
}

.element::after {
  content: '';
  position: absolute;
  top: 3px; left: 3px;
  right: -4px; bottom: -4px;
  border: 2px solid #3a3a3a;
  border-radius: 6px 22px 10px 18px;
  pointer-events: none;
  opacity: 0.1; /* 淡淡的第二层 */
}
```

### 5.3 虚线边框

仅用于 Slogan 横幅和菜单分割线：

```css
/* Slogan 横幅 */
border: 2px dashed #3a3a3a;
border-radius: 4px 16px 8px 12px;

/* 菜单分割线 */
border-bottom: 2px dashed #ddd;
```

- 线宽：**2.5px**（`stroke-width="2.5"`）
- 颜色：默认 `#999`，激活态 `#3a3a3a`

## 八、动画与交互

### 8.1 微交互原则
- **没有平滑的贝塞尔曲线动画**，所有变化都是「生硬」的短过渡（0.15s）
- 用**旋转**代替缩放作为主要反馈，模拟纸张被翻动的感觉

### 8.2 各元素交互

| 元素 | 默认态 | Hover / 按下 | 过渡时间 |
|------|--------|--------------|---------|
| 按钮 | 正常 | `rotate(-1deg) scale(1.02)` | 0.15s |
| 按钮 | 正常 | Active: `rotate(1deg) scale(0.98)` | 0.15s |
| 卡片 | 正常 | `rotate(-1deg) translateX(2px)` | 0.15s |
| 导航项 | 正常 | `rotate(-3deg)` | 0.15s |
| 拍照区 | 正常 | `rotate(-1deg) scale(1.01)` | 0.2s |
| 分类标签 | 正常 | `rotate(-1deg)` | 0.15s |
| 分类标签 | Active | `rotate(1deg)` | 0.15s |

### 8.3 页面转场
- 不使用小程序默认的滑动转场
- 建议直接使用**淡入淡出**（`opacity` 0→1，0.2s）或**无动画直接切换**
- 保持「翻手账」的干脆感

## 九、特殊效果

### 9.1 纸张纹理（可选）

在页面最上层叠加一层淡淡的噪点纹理，模拟素描纸质感：

```css
.page-container::before {
  content: '';
  position: fixed;
  top: 0; left: 0; right: 0; bottom: 0;
  background-image: url("data:image/svg+xml,..."); /* 噪点 SVG */
  pointer-events: none;
  z-index: 9999;
  opacity: 0.04;
}
```

> **注意**：小程序中 fixed 遮罩可能影响性能，v1.0 可先不加，v1.1 评估后再加。

### 9.2 元素微旋转

以下元素默认带轻微旋转，打破规整感：

```css
/* 标题 */
h1 { transform: rotate(-1deg); }
h2 { transform: rotate(-0.5deg); }

/* 头像 */
.avatar { transform: rotate(-3deg); }

/* 相机按钮 */
.camera-icon { transform: rotate(-2deg); }

/* 发现卡片缩略图 */
.find-thumb { transform: rotate(-2deg); }

/* 图标容器 */
.icon-box { transform: rotate(-2deg); }
```

## 十一、微信小程序适配注意

### 11.1 字体
- 微信小程序 **不支持加载外部字体文件**（如 .ttf/.woff）
- 使用 `font-family: 'Courier New', 'Menlo', 'Monaco', monospace;`
- iOS 上 Courier New 效果最佳，Android 上可能 fallback 到普通等宽体，需实测

### 11.2 边框
- WXSS 支持 `border-radius` 四个值分别设置（如 `border-radius: 4px 16px 8px 12px`）
- 双层边框效果需用伪元素 `::after` 实现，小程序 WXML 中可用 `view` 嵌套模拟

### 11.3 旋转
- WXSS 支持 `transform: rotate(-1deg)`
- 注意：旋转后的元素可能触发边缘裁切，适当留 `padding`

### 11.4 阴影
- **本风格不使用 `box-shadow`**
- 所有「厚度感」通过双层边框实现
