# 好奇图鉴数据库设计文档

> 版本：v1.0
> 关联 PRD：好奇图鉴_PRD_v1.4
> 关联技术架构：好奇图鉴_技术架构文档_v1.2
>
> 说明：本文档面向产品与开发协作使用，记录微信云开发数据库的集合结构、字段含义与建库步骤。

---

## 一、数据库环境

- **平台**：微信云开发（CloudBase）
- **数据库类型**：MongoDB 文档型
- **访问方式**：小程序端 SDK + 云函数 admin 权限
- **数据隔离原则**：所有用户数据以 `openid` 为过滤条件，禁止全表查询

---

## 二、集合清单

| 集合名 | 用途 | 权限规则 | 数据量预估 |
|--------|------|----------|-----------|
| `users` | 用户档案与统计 | 仅本人读写 | 与用户量 1:1 |
| `settings` | 用户隐私/功能设置 | 仅本人读写 | 与用户量 1:1 |
| `discoveries` | 用户的发现记录 | 仅本人读写 | 用户量 × 人均发现数 |
| `badges` | 徽章解锁进度 | 仅本人读写 | 用户量 × 徽章数量 |
| `species` | 物种主档（公共） | 全员可读，仅云函数可写 | 随识别物种增长 |

---

## 三、集合详细设计

### 3.1 users（用户档案）

用户首次进入小程序时自动创建。

```js
{
  _id: ObjectId,              // 云数据库自动生成
  openid: "wx_abc123",        // 微信 openid，唯一标识
  nickname: "好奇探索者",      // 昵称，用户可修改
  avatarEmoji: "🌿",          // 头像 emoji，用户可修改
  joinDate: ISODate,          // 首次使用日期
  lastLogin: ISODate,         // 最近一次登录
  streakCount: 12,            // 当前连续发现天数
  lastDiscoveryDate: ISODate, // 最近一次发现日期
  totalDiscoveries: 23,       // 累计发现物种数
  categoryCount: 5,           // 覆盖类别数（昆虫/植物/鸟类/菌类/动物）
  createdAt: ISODate,
  updatedAt: ISODate
}
```

**索引**：`openid`（唯一）

---

### 3.2 settings（用户设置）

与用户一一对应，单独存放可开关的隐私/功能配置。

```js
{
  _id: ObjectId,
  openid: "wx_abc123",
  locationEnabled: true,      // 地理位置记录总开关
  autoSaveToAlbum: false,     // 是否自动保存分享卡片（预留）
  compressQuality: 80,        // 压缩质量（预留）
  createdAt: ISODate,
  updatedAt: ISODate
}
```

**索引**：`openid`（唯一）

---

### 3.3 discoveries（发现记录）

用户每次点击「收入图鉴」后生成一条记录。

```js
{
  _id: ObjectId,
  openid: "wx_abc123",                    // 所属用户
  speciesName: "玉带凤蝶",                // 物种中文名（展示用）
  latinName: "Papilio polytes",           // 拉丁名，可能为空
  speciesKey: "papilio polytes",          // 归一化查重键（小写）
  category: "昆虫",                        // 枚举：昆虫/植物/鸟类/菌类/动物
  order: "鳞翅目",                        // 目
  family: "凤蝶科",                       // 科
  userPhotoUrl: "cloud://...",            // 用户照片 COS 地址
  thumbUrl: "cloud://...",                // 缩略图 COS 地址
  description: "翅展约 90-120mm...",      // 形态特征
  habitat: "常见于柑橘园...",              // 分布与习性
  confidence: 0.94,                       // 识别置信度；手动搜索为 null
  source: "baidu-animal",                 // 识别来源
  isManualSearch: false,                  // 是否手动搜索
  location: "奥森公园",                    // 逆地址解析后的文本地名，可编辑
  discoveredAt: ISODate,                  // 发现时间（不可编辑）
  rarityTags: ["首次发现", "连续 12 天"],  // 收藏时落库的标签快照
  isFirstDiscovery: true,                 // 收藏时是否为首次发现
  createdAt: ISODate,
  updatedAt: ISODate
}
```

**索引**：

- `openid + discoveredAt`（复合索引，用于图鉴列表按时间倒序）
- `openid + speciesKey`（复合索引，用于查重）

**重要约束**：

- **不存储精确经纬度**，只存储解析后的文本地名。
- `rarityTags` 落库后不重算，删除记录时标签快照保留。
- streak 只增不减，删除记录不影响历史徽章解锁。

### 3.4 badges（徽章记录）

用户首次使用时预创建全部徽章记录，后续只更新进度与解锁状态。

```js
{
  _id: ObjectId,
  openid: "wx_abc123",
  badgeId: "insect_apprentice",   // 徽章唯一标识
  badgeName: "昆虫学徒",           // 徽章中文名
  emoji: "🦋",                    // 徽章图标 emoji
  unlocked: true,                 // 是否已解锁
  unlockedAt: ISODate,            // 解锁时间
  progress: 5,                    // 当前进度
  target: 5,                      // 目标值
  createdAt: ISODate,
  updatedAt: ISODate
}
```

**索引**：`openid + badgeId`（唯一复合索引）

**v1.0 徽章列表**：

| badgeId | badgeName | 解锁条件 |
|---------|-----------|---------|
| first_nature | 初识自然 | 累计发现 >= 1 种 |
| insect_apprentice | 昆虫学徒 | 昆虫类累计 >= 5 种 |
| plant_walker | 植物行者 | 植物类累计 >= 10 种 |
| bird_observer | 鸟类观察家 | 鸟类累计 >= 3 种 |
| fungi_hunter | 菌类猎人 | 菌类累计 >= 5 种 |
| persistent | 坚持不懈 | 连续 7 天 streak |
| night_owl | 夜间发现 | 夜间发现累计 >= 3 次 |
| naturalist | 博物学家 | 累计发现 >= 50 种 |

> 注：「逆季节」「城市奇遇」为 v1.2 规划，v1.0 仅在徽章墙展示为锁定状态，不创建记录。

### 3.5 species（物种主档）

公共集合，所有用户共享。用于展示官方标准图和科普信息。

```js
{
  _id: ObjectId,
  speciesName: "玉带凤蝶",                // 中文名（展示用）
  latinName: "Papilio polytes",           // 拉丁名
  category: "昆虫",
  order: "鳞翅目",
  family: "凤蝶科",
  description: "翅展约 90-120mm...",
  habitat: "常见于柑橘园...",
  officialPhotoUrl: "cloud://...",        // 官方标准图 COS 地址
  officialPhotoStatus: "ready",           // ready / pending / failed
  imageSource: "iNaturalist",             // 图片来源
  imageLicense: "CC BY",                  // 授权协议
  originalImageUrl: "https://...",        // 原始外链
  // 以下字段 v1.2 规划使用，v1.0 可留空
  seasonData: {
    months: [4, 5, 6, 7, 8, 9],
    source: "manual_top_species",
    coverage: "partial"
  },
  isNocturnal: null,
  iucnStatus: null,
  firstCachedAt: ISODate,
  lastUpdatedAt: ISODate,
  createdAt: ISODate,
  updatedAt: ISODate
}
```

**索引**：

- `latinName`（唯一）
- `speciesName`（文本索引，用于手动搜索）

**权限规则**：

```json
{
  "read": true,
  "write": false
}
```

- 全员可读（展示官方图和科普信息）。
- 仅云函数通过 admin 权限写入（图片缓存、数据更新）。

## 四、云存储目录

```
cloud://env-id/
├── photos/                  # 用户原始照片
│   └── {openid}/
│       ├── 20260723_102345.jpg
│       └── ...
├── thumbs/                  # 用户照片缩略图（≤100KB，列表用）
│   └── {openid}/
│       ├── 20260723_102345_thumb.jpg
│       └── ...
└── species/                 # 物种官方标准图（公共可读）
    ├── papilio_polytes.jpg
    └── ...
```

**权限**：

- `photos/`、`thumbs/`：仅文件所有者可读写。
- `species/`：全员可读，仅云函数可写。

## 五、建库步骤

开通微信云开发后，按以下顺序操作：

1. 进入「微信开发者工具」→「云开发」→「数据库」。
2. 依次创建 5 个集合：`users`、`settings`、`discoveries`、`badges`、`species`。
3. 配置安全规则：
   - `users`、`settings`、`discoveries`、`badges`：`read/write` 均限制为 `doc.openid == auth.openid`。
   - `species`：`read` 为 `true`，`write` 为 `false`。
4. 创建索引（按上文索引列表）。
5. 在云函数代码目录右键选择「创建并部署：云端安装依赖」。

## 六、v1.0 与 v1.2 字段说明

| 字段 | v1.0 状态 | v1.2 状态 | 说明 |
|------|----------|----------|------|
| `discoveries.rarityTags` | 支持 3 种标签 | 新增反季节/城市奇遇 | v1.0 只存首次发现、连续 N 天、夜间发现 |
| `species.seasonData` | 留空 | 补充 Top 物种 | 依赖人工数据 |
| `species.isNocturnal` | 留空 | 补充 Top 物种 | 依赖人工数据 |
| `species.iucnStatus` | 留空 | 接入 IUCN API | 仅评估物种 |
| `badges` 逆季节/城市奇遇 | 不创建 | 创建并解锁 | v1.0 徽章墙展示为锁定状态 |
